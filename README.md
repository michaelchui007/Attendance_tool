# 考勤统计工具

面向个人的本地考勤统计桌面应用。导入企业微信考勤日报，查看实际工时、加班、调休扣减及净剩加班，并导出可追溯的 Excel 统计结果。

`Source code` 是源代码压缩包，无需下载它来安装软件。安装包包含运行环境，不需要另外安装 Python、Node.js 或 Rust。私有仓库需要使用具有访问权限的 GitHub 账号下载。

macOS 安装包目前未经过 Apple Developer ID 签名和公证。首次打开可能需要在系统隐私与安全设置中确认允许。发布页同时提供 SHA-256 校验文件。

## 主要功能

- **多报表统计**：选择或拖入同一员工的多份 `.xlsx` 日报，按日期合并，识别重复文件和来源冲突，查看区间及分月汇总。
- **每日核对**：查看上下班时间、工时、调休扣减和计算说明，追溯原始申请及来源文件。
- **人工修订**：修改每日上下班时间，或独立指定调休扣减，处理公司统一调休等源表未记录的情形。修订原因可选，未填写时记录为“手动调整”。
- **系统配置**：设置标准工时、正常上下班、午休和日期段作息；在每日详情中设置单日例外。
- **Excel 导出**：保留每日结果、原始记录、人工修订、计算规则和文件来源。
- **随报表携带配置**：将规则与修订保存到源 Excel 的专用工作表，换电脑后导入可选择恢复。

本分支包含 v0.3.1 的功能；可下载安装的版本以 Release 页面为准。

## 快速开始

1. **设置规则**：打开“系统配置”，核对标准工时、正常上下班及午休。默认标准工时为每天 8 小时。
2. **添加报表**：选择或拖入一份或多份 Excel。同一次统计应使用同一员工的报表。
3. **开始统计**：查看处理进度，按提示解决来源冲突或移除无法读取的文件。
4. **核对结果**：查看待处理原因及建议动作，必要时编辑打卡时间或手动调休扣减；原因可选填。
5. **保存并重算**：确认修订后生成新的统计结果。默认导出到首个加入文件所在目录的 `export_report` 文件夹，也可指定输出目录。

修改系统配置后，已有结果会提示需要重新统计。普通统计和导出不修改源 Excel。需要换电脑继续使用时，可在保存并重算后点击“保存配置到源 Excel”；软件先备份原文件，再写入专用配置工作表，原始考勤工作表保留。已有导出文件保持原样。

## 作息与计算规则

| 设置 | 默认值 | 作用 |
|---|---|---|
| 标准工时 | 8 小时/工作日 | 计算应计标准、加班和自动调休扣减上限，可独立修改 |
| 正常上班/下班 | 09:00 / 18:30 | 与午休共同确定请假可计入的工作时段 |
| 午休 | 12:00–13:30 | 工作日只扣除与实际打卡区间重叠的部分 |
| 考勤日边界 | 04:00 | 次日 04:00 前的打卡归入前一考勤日 |

标准工时不会随上下班或午休设置自动改变。日期规则按“单日设置 → 日期段规则 → 默认作息”的优先级生效，同级日期段不能重叠。

- 实际有效工时根据真实打卡计算，不被正常作息窗口裁剪。
- 工作日加班为实际有效工时超过所配标准工时的部分，最低为零。
- 休息日不计应计标准、不扣午休，完整打卡跨度计入加班；国家安排上班的调休周末仍按工作日处理。
- 自动调休扣减先按申请区间分配到工作日；打卡完整时，不超过当天剩余标准工时，也不超过当日申请量。
- 人工调休扣减替代自动扣减。填写“扣减 8 小时”表示余额减少 8 小时；手动填写 0 与恢复自动计算是不同操作。
- 净剩加班为加班减去实际调休扣减，允许为负数。不计半小时地点福利。

缺卡日期的实际工时显示为未计算。无法确定的扣减显示为待核对，不按零处理。报表之间缺少的日期标为未导入，不作为零出勤或整月缺卡计算。

待处理清单显示具体问题和建议操作。人工扣减保存后，与该扣减相关的缺卡或调休待核对项标为已处理，不再重复列为待办；原始缺卡信息仍保留。来源冲突、上下班时间倒置等独立问题仍需处理。

## 数据与使用范围

- 考勤读取、计算和导出均在本机完成；联网用于更新节假日安排，不上传考勤内容。
- 支持企业微信个人日报 `.xlsx`，不支持旧版 `.xls` 或多人合并统计。合并多份报表需要有效的员工账号，不能仅凭同名确认身份。
- 自动识别范围为调休申请；年假、事假、病假等不会自动作为调休扣减。
- 系统配置保存在本机。每日修订默认保留在当前会话；主动保存到源 Excel 后，规则和修订可随文件迁移。导入检测到配置时，先选择使用软件配置或 Excel 配置，后者仅用于本次统计，不自动替换本机默认值。
- 配置工作表不保存本机输出目录或其他绝对路径。文件中的配置须通过格式、员工及原始数据校验；未知版本或损坏配置可以忽略，不会被自动执行或套用。
- 多份文件内容矛盾时，应先选择采用的来源；部分月份未导入时，汇总只代表已覆盖数据。

## 常见问题

**为什么申请 5 小时，实际只扣 4 小时？**

当标准为 8 小时、当天实际工作了 4 小时，只剩 4 小时标准工时需要补足，因此自动扣减最多为 4 小时。原始申请仍保留在详情中。

**没有请假申请，可以登记公司统一调休吗？**

可以。在对应日期的“编辑考勤”中启用手动调休扣减，填写时长后保存并重算；原因可留空，不需要补造打卡记录。

**换电脑后如何保留修订？**

先保存并重算，再点击“保存配置到源 Excel”，确认各文件保存成功。复制包含专用配置工作表的源报表到另一台电脑，导入时选择使用 Excel 配置。写入前的备份路径会显示在保存结果中；文件被占用或没有写入权限时，请关闭 Excel 或调整保存位置后重试。

**为什么显示“待核对”或“未导入”？**

“待核对”表示源记录存在无法自动确定的内容；“未导入”表示文件集没有覆盖该日期。请查看提示并补充报表或处理来源冲突。

**导出文件在哪里？**

统计成功后页面显示输出位置。可在系统配置中指定目录；重复导出会生成新的文件，保留历史结果。
