# 考勤统计 v0.3.0

## 更新内容

- 全新考勤工作台：重点展示净剩加班，支持每日筛选、计算详情与原始记录追溯。
- 支持拖入单个 Excel、修订每日上下班时间、补卡、恢复原值及保存后重算导出。
- 修复跨日调休重复扣减：按工作时段分摊，并排除实际休息日。
- 完整打卡时，调休扣减不超过当天剩余标准工时，也不超过申请量。
- 永久取消半小时地点福利；考勤日边界调整为 04:00。
- 支持手动配置午休，正常工作时段保持每天 8 小时。
- 完善无法识别申请、混合假种、日期冲突等提示，未知扣减不会被当成零。
- 导出保留原始数据、时间修订与计算规则；重复导出不覆盖已有结果。

## 安装包

- Windows x64：NSIS `.exe` 安装程序。
- macOS Apple Silicon：`aarch64_unsigned.dmg`。仅含 ad-hoc 签名，未进行 Apple Developer ID 签名和公证，首次打开可能需要在系统安全设置中允许。
- `SHA256SUMS.txt` 提供两平台安装包的 SHA-256 校验值。

## 验证与使用边界

- 47 项 Python 测试通过，包含 17 项真实报表形态及补充边界的脱敏回归。
- 前端构建、Rust 检查与 13 组页面/引擎联调通过；发布流程再次执行双平台测试及安装包构建。
- 时间修订保留在当前文件会话，不自动跨次打开恢复；原始 Excel 不被修改。
- 部分缺卡、无起止区间申请沿用保守处理并提示核对。新规则复算历史报表可能与旧版结果不同。
- 未进行 Windows/macOS 安装包图形界面的完整实机验收，建议首次使用时核对已知报表结果。
