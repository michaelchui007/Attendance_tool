# 考勤统计 v0.3.2

## 计算修复

- 修复完整工作日的实际工时不足标准时，净剩加班错误显示为 0 的问题。标准为 8 小时、实际为 7.5 小时，且无调休申请或手动扣减时，净剩为 −30 分钟。
- 新增独立的“工时不足扣减”，用于展示不足标准的差额，不混入调休扣减。每日详情、分月汇总、期间总计和 Excel 导出采用一致口径。
- 更新净剩加班说明：净剩 = 加班 − 调休扣减 − 工时不足扣减。

## 适用范围

- 工时不足扣减仅用于打卡完整且有效、无调休申请、未手动指定扣减的工作日，包括国家安排上班的调休周末。
- 有调休申请时保留原有分摊与扣减上限规则，不再叠加工时不足扣减。例如标准 8 小时、实际工作 4 小时，申请 2 小时只扣 2 小时，申请 5 小时最多扣 4 小时。
- 手动指定扣减优先，填 0 表示明确不扣减；恢复自动计算后重新按当天记录核算。
- 年假、病假、事假等其他假勤不自动豁免工时不足；确认当天无需扣减余额时，可手动指定扣减为 0。
- 休息日工时仍完整计入加班；缺卡、异常时间、未导入日期和未解决来源冲突，不推定为全天工时不足。

## 升级说明

升级后重新统计可获得修正后的结果；已有导出文件不会被改写。请核对系统配置或报表中恢复的标准工时、午休及每日修订，确保计算使用预期规则。
