# 考勤统计 v0.3.1

## 功能更新

- 新增独立系统配置页面：标准工时默认 8 小时，可独立修改；正常上下班、午休和日期段规则可配置并保存在本机。
- 支持每日作息例外，优先级为单日、日期段、默认作息；支持无午休。
- 支持手动调休扣减及原因记录，可单独登记公司统一调休，不要求补造上下班记录。
- 支持多选和拖入多份同员工报表，合并时间线、识别重复及来源冲突，并显示分月汇总和未导入日期。
- 复用未变化的解析数据，增加处理进度、分阶段耗时和取消操作。
- 导出增加来源清单、规则和修订审计；普通统计不修改原始文件。

## 测试反馈改进

- 手动扣减原因改为选填，留空记录为“手动调整”。
- 人工扣减保存后，相关缺卡/调休待办标记已处理并从待处理清单移除；原始异常仍可追溯。未处理项显示具体原因和建议动作。
- 页脚“关于”显示作者 MichaelChui 与版本，软件包元数据同步署名。
- 新增“保存配置到源Excel”：显式写入专用配置工作表，先备份，保留原始考勤工作表；换电脑或改名后导入可选择使用Excel配置或软件配置。

## Windows 修复

- 统一文件选择、拖放、输出目录及引擎通信中的 Unicode 路径传递，显式设置标准输入输出编码。
- 正式主程序使用 Windows GUI 子系统，后台引擎不显示控制台并在关闭时清理。
- 新增真实 Windows 安装包自动化验证，检查冻结引擎、中文路径、WebView2 界面和原生文件对话框。实际执行记录见开发分支验证报告。

## 使用说明

- 修改标准工时不会自动调整正常上下班或午休；修改作息也不会自动改变标准工时。
- 人工扣减替代自动值，填 8 小时表示余额减少 8 小时。恢复自动扣减不会清除打卡修订。
- 系统配置本地保存；每日修订默认保留在当前会话，主动写入源Excel后可随报表迁移。普通计算仍不改源文件。
- 源报表被Excel另存或被其他程序修改后，严格的原始内容校验可能使旧配置失效；界面会提示，不自动套用。
- 来源冲突未解决时不生成可误用的合并导出；未导入日期不自动按缺卡处理。
- macOS 安装包仍未经过 Apple Developer ID 签名和公证。

## 安装包

- Windows x64：`AttendanceTool_0.3.1_windows_x64_setup.exe`。
- macOS Apple Silicon：`AttendanceTool_0.3.1_macos_arm64_unsigned.dmg`。
- `SHA256SUMS.txt` 提供两平台安装包校验值；DMG另附独立校验文件。
