## Windows 安装包测试方案

使用 `.github/workflows/test-windows.yml` 在 Windows runner 上：

1. 执行Python/Rust回归，构建真实NSIS安装程序。
2. 静默安装到中文目录。
3. 用安装目录中的冻结引擎处理中文路径，移除强制编码环境变量，发送真实UTF-8中文JSON，验证导出可读。
4. 对1/3/12月文件集分别测量5轮，记录启动耗时、各阶段耗时、缓存命中及内存。
5. 安装与WebView2运行时匹配的Edge WebDriver，通过Selenium驱动已安装应用；用Windows原生自动化操作文件对话框和Explorer拖放。
6. 检查主程序GUI子系统、可见控制台及退出后的子进程清理，保存截图和日志。
